# 🧠 AdimenTIK - Base Boilerplate

Repositorio maestro y plantilla reutilizable para el desarrollo de soluciones de Inteligencia Artificial y automatización de **AdimenTIK** (Bilbao, España).

## 🏗️ Stack Tecnológico (Capa Gratuita)
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (Desplegable en Vercel/Netlify/GitHub Pages).
- **Backend & Base de Datos**: Supabase (PostgreSQL, Auth, Row Level Security).
- **Automatización**: Make.com (Webhooks) / GitHub Actions.

## 🚀 Inicio Rápido
1. Clonar este repositorio para un nuevo proyecto.
2. Configurar las variables de entorno (`.env`) con las credenciales de Supabase.
3. Ejecutar el script `setup.sql` en el Editor SQL de Supabase.
4. Configurar el webhook en Make.com para la automatización de correos.

## 🤖 Agentes Asignados
- **Arquitecto**: Infraestructura y Base de Datos.
- **Manitas**: Desarrollo Frontend/Backend.
- **Enrutador**: Automatizaciones y Webhooks.
- **QA**: Revisión de seguridad y límites de capas gratuitas.
